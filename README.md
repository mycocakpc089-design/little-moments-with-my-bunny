# To My Last Love — romantic letter website

A mobile-friendly, single-page love letter with a moonlit dark-green sky, subtle animated stars, a sealed envelope, and your full letter. No music and no external libraries.

## Preview on your computer

1. Download and unzip `last-love-website.zip`.
2. Open the folder.
3. Double-click `index.html` to open it in your browser.
4. Test the envelope button on your phone too if you can.

## Publish it free with GitHub Pages

1. Sign in or create an account at https://github.com/
2. Create a new repository. Name it `last-love-letter`.
3. Set it to **Public** (GitHub Pages free hosting generally requires a public repository on a free plan).
4. Choose **Add file → Upload files**.
5. Upload `index.html` from this folder. Make sure the file is named exactly `index.html` and is at the repository's top level.
6. Click **Commit changes**.
7. Open the repository's **Settings → Pages**.
8. Under **Build and deployment**, choose **Deploy from a branch**.
9. Select branch `main` and folder `/(root)`, then click **Save**.
10. Wait a minute or two. GitHub will show the website address on the Pages settings screen. It will usually look like:
   `https://YOUR-USERNAME.github.io/last-love-letter/`
11. Open that address on your phone to test it, then send the link to your bunny when you're ready.

## Personalization

Open `index.html` in a text editor to change the text or colors. The full letter is already included exactly as provided in the chat.

## Privacy note

GitHub Pages sites are public. Anyone who has the link may read the letter, and the URL can be forwarded. Avoid adding private details such as addresses, passwords, or other sensitive information.
